
# BLUETEETH Patient Management Portal

## Features
- Firebase Authentication
- Patient Records
- Free Camp Patients
- Clinic Visit Patients
- Report Upload
- Doctor Management
- Dashboard Analytics
- Search & Filters

## Tech Stack
- React + Vite
- Firebase
- Tailwind CSS
- Firestore
- Firebase Storage

## Installation

```bash
npm install
npm run dev
```

## Firebase Collections
- patients
- doctors
- admins
- reports
